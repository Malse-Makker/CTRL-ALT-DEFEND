CTRL-ALT-DEFEND — alpha v0.65.0
=====================================
I'll put this with the rest of the focus.

A top-down tower defense about defending your workday. Meetings that could
have been an email, reply-all storms and consultants march toward your desk —
stop them with coffee machines, headphones and office artillery.

HOW TO RUN (Windows)
--------------------
1. Unzip anywhere.
2. Double-click CTRL-ALT-DEFEND.exe
3. Windows SmartScreen will probably complain (the game is not signed).
   Click "More info" -> "Run anyway". That's expected for an alpha build.

Linux: the game runs fine through Proton or Wine (add the .exe to Steam as a
non-Steam game and enable Proton, or just `wine CTRL-ALT-DEFEND.exe`).

CONTROLS
--------
- Mouse: build, upgrade, sell towers
- 1-9, 0, Shift+1..4: select a tower
- Space: call the next wave early (bonus points)
- P: pause  ·  +/-: game speed  ·  Escape: back

THIS IS AN ALPHA
----------------
The maps are greybox (grey floors, colored blocks), there is little art and
the balance has not been play-tested yet. That is exactly what you are here
for. Everything else — 15 levels, promotions, bosses, special modes — works.

FEEDBACK (please!)
------------------
The game logs anonymous playtest data locally (difficulty ratings, what you
built, what got through). Nothing is sent anywhere automatically.

When you are done playing:
1. Go to the main menu -> FEEDBACK
2. Vote on the plans (the arrow turns green or red), fill in whatever you like
3. Click COPY ALL TO CLIPBOARD
4. Paste it straight into Discord and send. Thanks!

(There is also a "Save as files" button that writes a .txt and .csv to your
Downloads folder — only needed if copy-paste fails for some reason.)

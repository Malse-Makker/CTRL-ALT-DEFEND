Windows will complain — that's normal

The game is unsigned, so your browser may ask whether to keep the file, and SmartScreen shows a warning the first time you run it. Choose Keep, then More info → Run anyway. Both are expected for an alpha that nobody has paid a certificate authority for.

On Linux?

Add CTRL-ALT-DEFEND.exe to Steam as a non-Steam game and enable Proton, or run it directly with wine CTRL-ALT-DEFEND.exe.

This is an alpha

The maps are greybox (grey floors, colored blocks) and the balance has never been play-tested. That is exactly what you are here for. The game itself is complete: 15 levels, promotions, bosses, special modes.

Feedback — the whole point

  1. Play a few levels (or a lot). After each one, rate how much fun it was.
  2. Main menu → FEEDBACK: vote on plans, write whatever you like.
  3. Send it back whichever way suits you: COPY ALL TO CLIPBOARD and paste it into Discord, a text file or pastebin — or hit the email button and it goes to games@makkers.net.

The game logs playtest data locally only; nothing is sent anywhere automatically. Your feedback includes which version you played each level on, so reports about already-fixed things can be spotted.

What's new & verifying your download

Every version is listed on the changelog page, together with the SHA-256 checksums of this release. The game shows the first 12 characters of its own checksum at the bottom of the main menu, so you can check the two match.

The download button always gives you the newest release. The game also checks for updates on startup and can update itself, so this is the last time you need to fetch it by hand.
